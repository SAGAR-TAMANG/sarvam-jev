The state is prefilled into a KV cache exactly once. Each criterion then branches off that cache carrying only its own question and options, so no criterion can see another's text. Two forward passes in total, however many criteria you ask.

What these numbers do — and do not — mean

Conditional probabilities. The readout is a softmax over only the option letters you supplied. It is not calibrated confidence, and a high value does not establish that the decision is right.

A 2B base model. sarvam-1 was never instruction-tuned. It scores 0.516 mean family balanced accuracy on openjev's authored fixture against a 0.333 chance floor — well above chance, well below instruction-tuned models of the same size.

Real local timing. Prompt construction, tokenization, prefill, branch evaluation and decode are all inside the timed region. Model load and warmup are not.

Watch the verdict line. Generation usually emits valid JSON with every key present, then fills a criterion with an option id belonging to a different criterion. A schema validator accepts that. The typed readout cannot express it.
